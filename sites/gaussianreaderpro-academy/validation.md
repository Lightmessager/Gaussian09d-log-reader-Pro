能量 SVG 原先将顶部节点和底部标签放在同一按钮组，组中心落在空白处。定位后将可访问按钮放到节点点击圆上；复验可通过具名按钮选中 TS，并完成课程。

## 范围与限制

网页使用合成教学数据；不执行 Gaussian，不读取用户真实日志，不更改桌面项目。分子连线、频率谱线、IRC 结构及立体图为教学示意；立体图只改变显示角度，不代表完整桌面三维相机或势能面。

使用浏览器自动化验证了音效启动/关闭状态，未对实际扬声器音质作主观验收。没有运行不相关的桌面 Qt 全仓库测试。

离线单文件已通过全部 5 段内嵌脚本的语法检查；ZIP 完整性通过。浏览器工具禁止 file 协议，因此交互验收使用已允许的 localhost 原始网页，未宣称浏览器工具已直接验收 file 协议离线版。离线包没有远程脚本、字体或音频依赖。
