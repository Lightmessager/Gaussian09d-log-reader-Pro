## 语法与行为

```text
@{TS1} - (@{R} + @{A})
0.5 * @{species (2)} + 1[kcal/mol]
@{中文-物种名} + 2[kJ/mol]
```

文件名为显示信息；别名编译为精确的文件 UUID/作业 UUID/能量策略。没有前缀匹配。别名索引允许搜索建议、去重分配与重命名；项目保存 alias_bindings，使无效草稿跨会话保留同一命名空间。

无单位数只作系数，能量偏移必须有单位。能量×能量、除以能量、调用、属性、索引、幂、bool、非有限数、除零和超限表达式被拒绝。完整自定义 AST 同样受校验，含环/过深结构在冻结前被拒绝。

体系表达式与直接差值使用明确 purpose；路径分 relative、absolute、direct_difference。差值不能再附加参考。不会从减号猜意图，因此 S6 必须让用户清楚选择模式并显示完整“节点体系能量−参考”关系。

高低级别 Gibbs 模板为 `E_high + (G_low - E_low)`，三个引用固定类型，低层 G/SCF 必须来自同一作业，输出有组合近似警告。标准表达式不能静默混合 SCF 与 Gibbs 总值。已识别条件不一致为警告，未知条件为信息提示，均保留来源。

## 验证

全量 `python -m pytest -q --tb=short`：**139 passed**，保留全部 71 项 S0/S1 检查，新增 68 项 S2 场景。

- 精确别名、重复文件名、中文/短横线名称、改名后的 UUID 与值不变、完整 UUID token 文本往返。
- 运算优先级、系数、括号、单位类型和常量；恶意/非法语法不会执行。
- 字符/节点/深度限制，非有限值、算术溢出、分母零，直接 AST schema 与环检测。
- 参考只扣减一次；直接差值与体系相对值相同；零参考有效；缺参考保持无效状态。
- 同一节点在不同路径具有不同参考与顺序；单位变化不改 Hartree 原值。
- 缺源/缺作业/缺字段、取消/stale 状态不能补 0；无效草稿不会输出旧有效值。
- 异常终止需显式 opt-in；明确 SCF 不收敛仍阻止计算；其他字段问题不会冒充当前字段错误。
- 高低级别模板约束，以及真实 cclib 单点/频率组合结果和 3857/457/2061 来源行号。
- 批量操作原子预览、修订冲突、精确替换、重排、引用保护和显式级联。
- 项目别名只读且可序列化，删除保护涵盖旧 AST 与草稿中的完整新引用 token。
- 新进程 python -S 可导入完整核心而不加载 UI/绘图库。

## 端到端人工 oracle

演示源是明确标记的合成日志，R=-100、A=-50、TS1=-149.976、I1=-140、B=-10.008、P=-150.025 Hartree（Gibbs 总值）。节点为 R+A、TS1、I1+B、P；参考 R+A=-150 Hartree。

| 节点 | 体系能量 / Hartree | 相对值 / Hartree | 相对值 / kcal·mol⁻¹（显示舍入） |
|---|---|---|---|
| R + A | -150 | 0 | 0 |
| TS1 | -149.976 | +0.024 | +15.060227 |
| I1 + B | -150.008 | -0.008 | -5.020076 |
| P | -150.025 | -0.025 | -15.687737 |

同一 TS1 的直接差值结果与路径相对值完全一致。运行结果保留 float 精度，不用显示舍入值继续计算。容差验证通过。

运行 `tools/check_s2.py` 生成：

- `artifacts/s2/validation.json`：体系/参考/相对值、来源、直接差值、kJ 视图与批量预览。
- `artifacts/s2/project-snapshot.json`：完整项目输入、稳定引用、别名命名空间与公式树。
- `artifacts/s2/demo-logs/`：人工合成的输入日志，可直接检查每项来源。

当前 Windows/Python 3.12 主机测量：100 节点计算约 **1.58 ms**；整个小型演示约 **4.32 ms**。该测量包含共享来源的 100 节点计算，不含 UI、绘图与文件读取，不能据此承诺整个界面刷新耗时。

## 交接到 S3

持久化必须保存 Project、所有输入快照、alias_bindings、表达式 purpose/combination_mode/AST/草稿、路径顺序与参考、单位版本、修订和工作区状态。别名表不能根据当前排序再生成。无效草稿和缺参考路径是可保存的工作状态，加载后计算仍须保持 invalid。

严格重建 dataclass/枚举/引用并再次校验 AST；JSON 投影不是已实现的加载器。事务失败不得更新 saved_revision。历史结果如果缓存用于缺源时查看，应单独标注历史/过期，不能冒充当前 valid 计算。

当前没有自动校验全部化学计量、过渡态性质或所有方法兼容性。GUI、SQLite 和三维图表按后续阶段实施；已有 S0 演示包仍为固定数据原型，本阶段未重建它。
