# GaussianReadPro 液态玻璃改版任务书

状态：G1–G3、G5–G6 已完成，下一阶段 S8。用户要求暂不继续底层崩溃排查、继续开发，使用本机临时核心排除方案；G4 默认调度稳定性问题仍未关闭。2026-10-15。基线为已完成的 S7。用户要求薰衣草紫与落日橙，由成本较低的模型逐步完成代码。本方案作为 S7 后的 UI 专项 G1–G6，不覆盖原有科学与存储验收。

## 1. 视觉方向与范围

采用“薰衣草薄雾 + 落日暖光”的桌面研究工作台：背景有低饱和紫/橙环境光，导航、工具栏和卡片有半透明材质、细亮边与轻微厚度感，数据阅读面保持稳定对比。紫色承担导航、选择和焦点，橙色承担当前主要操作和少量强调。参考示意为 docs/design/liquid-glass-concept.png；它是布局/配色提案，不是运行截图，也不证明动态模糊已实现。

此次覆盖首页、来源页、路径页、表格、属性面板、表达式/批量编辑、菜单/提示/状态、二维/三维图表、放大窗口、CN/EN、浅深色、窄窗口和显示缩放。保留 PySide6 Widgets + Plotly，避免重新搭建前后端和业务桥接。

“液态玻璃”在本方案中的可验收表现：透出应用自身环境底色的材质、顶部弧形高光、清晰内外边缘、柔和悬浮层次及短促状态过渡。首版使用跨平台 QPainter/QSS 拟态，不承诺苹果系统级实时折射或读取桌面背景。真实逐像素折射/任意内容背景模糊是额外技术项目，需要先做独立性能原型，不让实现模型自行扩展为全框架迁移。

- 背景环境光：左上薰衣草、右下暖橙，径向渐变边缘平滑，静态且低饱和；文字区不放高频纹理。
- 材质三层：导航/工具栏为玻璃层；数据卡片为 90–97% 不透明阅读层；菜单/提示/下拉为 96–100% 不透明浮层。玻璃层可以从 75–85% 表面覆盖率试起，逐主题调优。
- 卡片圆角 20–24 逻辑像素，工具栏 16–20，按钮/输入框 10–12，小徽标 8；不要把所有控件做成大胶囊。
- 网格间距 4/8/12/16/24/32；主区边距 20–24，卡片内边距 16–20。正文 13–14，表格 13，标题 22–26，辅助 12。随系统 DPI 缩放。
- 按钮常规高 34–38，表格行高 32–36；顶部避免三个同级大号主按钮。数字列右对齐、稳定小数格式；源码/表达式使用本地等宽字体回退。
- 图标用同一套本地 SVG 线形图标，16/20/24 三档，明确 accessibleName/tooltip；替换目前 ◈、▤、⌁、⤢ 等依赖字体的字符图标。

响应式使用逻辑尺寸：宽度 ≥1280 显示完整导航和检查器；1024–1279 折叠导航、检查器按需打开；860–1023 顶栏次操作进入更多菜单，筛选控件可分两行。最小窗口沿用现有 860×680 约束；检查屏幕可用高度，不只看宽度。图表高度不足约 300 时优先提供清晰的图表优先/放大入口，紧凑 3D 用悬浮代替拥挤常显文本。切布局复用同一 WebEngine，保存/还原 splitter，不能改变路径数据或自动保存窗口的临时挤压为永久首选布局。

## 4. 实现路径：低成本模型按这些边界写

### 4.1 集中 tokens 和基本组件

建议新增 resources/themes/lavender_sunset.json 和不依赖 Qt 的 presentation/palette.py，内容包括浅/深主题色、字号/间距/圆角、材质和图表显示色。纯 Python loader 缓存读取并校验必要键；资源必须通过包内路径定位。pyproject.toml 增加 themes/*.json、icons/*.svg 打包项。

ui/theme.py 保留 apply_theme(app, theme) 调用形式和 bool 返回值，从 tokens 生成 QSS，并设置 QPalette，覆盖菜单、QDialog、QMessageBox、QInputDialog、QTabWidget、QSpinBox/QDoubleSpinBox、复选框、选中/禁用/焦点和表格 viewport。避免继续向 main_window.py 散落 setStyleSheet 字符串。

新增 ui/glass_widgets.py：BackdropWidget 负责绘制/缓存应用环境底图；GlassPanel(QFrame) 绘制圆角填充、低对比边缘和顶部高光，提供 surface/elevated/toolbar 三种 variant。内容仍是正常 layout/原生子控件；不改变已有信号槽和 objectName。高光与阴影在背景 paintEvent 中完成，不能在数据之上罩一层截获点击的 widget。

背景缓存仅在尺寸、DPR、主题或效果模式改变时刷新；主窗口与卡片共用同一坐标系/底图。首版使用低频渐变形成柔化感即可。若尝试缓存模糊，只处理应用自有装饰底图，禁止在 paintEvent 中 grab 根窗口或抓取含自身的子树，避免递归/黑帧。不要给每个表格单元格创建 QWidget。

Qt QSS 的支持属性不等于浏览器 CSS；不要写 backdrop-filter、box-shadow、transition 指望生效。QGraphicsBlurEffect 模糊的是源内容；给整张卡片设置会连文字一起模糊。不要在 QWebEngineView 或其祖先上加图形模糊/透明度效果；该区域用外围背景与边框承载玻璃感。依据见文末 Qt 文档。

### 4.2 图表与导出适配

- ui/profile_view.py 选择图表浅/深主题后，附加可 JSON 序列化的 visual_style 显示字段；同一纯 Python palette loader 可供导出使用，core 不导入 ui/Qt。
- resources/plot/profile.js 的文字、背景、网格、零线、标签底/引线、选中态从 visual_style 读取，缺失时有稳定默认值。扩展为协议 2 可选字段，不必仅因配色升级协议号。继续保留 project/revision/render_id 与来源验证。
- 绘图区使用均匀近白/深紫底，WebEngine 页面背景与 Qt 容器匹配。不要把强渐变、折射、阴影加在数据曲线上；3D 保持路径类别轴和现有数值。
- 路径颜色属于用户项目数据，不能因为换主题批量改写。原有 path.color 原样使用；只修改空缺颜色的显示回退。新路径的推荐配色可在现有颜色菜单明确选择：紫 #8D6AC8、橙 #CF733D、蓝 #4D7FC2、青 #31847D、玫红 #B65A85；仍需按背景检查辨识度。
- 选中态优先外圈/尺寸，路径本色仍可辨识；确保图例颜色不会因首点选中变成统一橙色。原生 ui/profile_preview.py 同步样式，并保留缺失点空隙和明确 TS 形状。
- 二维论文导出继续白底、深字和清晰轴线，保留路径颜色、坐标、单位/参考/来源，不输出玻璃装饰；HTML 可带显示主题，但保持离线。三维 PNG 继续真实捕获。新字段不得破坏当前 assert_current_payload 和清单校验。

### 4.3 动效、偏好与兼容

hover/focus 约 120–160ms，按下反馈约 80–100ms，面板状态过渡最长 180ms。只对有限的可见控件做颜色/边缘过渡，不做持续漂浮光球、鼠标跟随折射、数据值动画或每帧重绘表格。进入/离开控件须停止/复用动画，不能重复注册事件。

外观设置增加“减少视觉效果 / Reduce visual effects”和“减少动态效果 / Reduce motion”。减少视觉效果使用实色面、边框和静态选中态，功能完全相同；减少动态效果立即改变状态。应用设置写 LocalPreferences，不能写科研 project 或增加其 revision。

注意 preferences.py 当前用 set(values)==set(DEFAULTS) 严格检查：新增键必须先识别现有合法 v1 键集、补默认、再严格验证，未知键和错误类型仍报错。明确为旧 v1 缺少新键做兼容，不能宽松接受任意缺字段。建议新键 visual_effects=standard|reduced、reduce_motion=bool；默认 standard、false。用户选择经现有 controller.update_preferences 排队保存，迁移失败不覆盖旧偏好。SQLite schema 不变。

跨平台以普通不透明顶层窗口+应用内部玻璃材质作为共同路径，保留原生标题栏、窗口拖拽和系统快捷键。不增加 Win32 DWM/macOS 私有材质调用或强制无边框；如将来增加平台原生增强，必须独立可禁用且不影响共同路径。

## 6. 验收标准：防止“颜色换了就算完成”

视觉矩阵至少包含：浅色中文宽窗、深色英文宽窗、两种主题紧凑窗；来源含缺失/失败行；公式编辑有效/无效及补全浮层；批量预览；二维比较与三维放大；减少视觉效果；导出中文/希腊字母。截图来自真正 Qt 窗口，不用 HTML mock 替代实测。示意图不是逐像素要求，布局需要服从 Qt 可读性和真实内容。

- 窗口：1440×1000、1100×820、860×680 逻辑尺寸，至少当前平台检查 100%/150%/200% DPI。英文控件不挤掉主要按钮；窄屏可访问全部操作；不能通过强制增大最小窗口来回避适配。
- 输入/状态：hover、pressed、focus、selected、disabled、busy、error、read-only 都有可区分表现；Tab 顺序与可访问名称可用。避免透明菜单叠在图表后无法读字。
- 科学与工作流：四节点 oracle、错误草稿、相同文件名、当前来源指纹、表格排序、不同参考、TS 势垒边界、保存/恢复/只读、导出与项目修订检查保持原行为。纯换主题不改变项目数据、选择、公式或科研 revision。
- 图表：连续 100 次更新/主题切换不累计监听器和实例；2D/3D 切换和放大后视口保留；WebGL 失败有清晰后备。所有颜色映射必须基于同一显示规范。
- 性能：记录同机/同数据下改版前后冷启动、空闲 CPU、滚动/调整窗口响应及连续交互内存；背景缓存只随尺寸/DPR/主题失效，空闲不持续绘制。若显著退化，优先简化特效并记录原因；不要编造 FPS/跨平台通过。完整负载测试继续属于 S8。
- 平台：Windows/macOS/Linux 的代码路径均用 Qt/pathlib、包资源与系统字体回退；只对实际运行的平台标通过。S9 冻结包须验证新增 JSON/SVG 的打包与离线读取。

优先复用 tests/test_workbench.py、test_node_editor.py、test_plot_spec_export.py 和 tools/check_s4.py、check_s6.py、check_s7.py；断言真实行为，避免逐色值或逐控件实现细节的脆弱测试。为偏好迁移/新增行为补针对性测试。每阶段运行受影响检查，G6 运行一次全量与原生验收；没有新变更/失败时不反复全量重跑。可新增 tools/check_glass_ui.py 生成独立配置的截图矩阵，不能覆盖用户偏好/项目。

## 8. 技术与模型依据

Qt QSS 属性范围：[Qt Style Sheets Reference](https://doc.qt.io/qt-6/stylesheet-reference.html)。模糊作用于源内容：[QGraphicsBlurEffect](https://doc.qt.io/qt-6/qgraphicsblureffect.html)。图形效果会作用于子控件，并对 OpenGL 控件有约束：[QWidget::setGraphicsEffect](https://doc.qt.io/qt-6/qwidget.html#setGraphicsEffect)。据此，本项目选择 QPainter 材质背景和独立绘图区，避免整体 blur 效果。

模型分工参考 [OpenAI Model selection](https://developers.openai.com/api/docs/guides/model-selection)，2026-10-15 查询；G1–G6 划分、具体 effort 与升级条件是本项目实施建议。减少总花费主要靠固定设计、限制改动边界、短交接及避免重复全量测试，而不只是把所有任务塞给一个便宜模型。
